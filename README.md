# RISC-V-Single-Cycle-Processor
Designed and implemented a 32-bit single cycle RISC-V processor using Verilog HDL.
# 32-bit RISC-V Single Cycle Processor

## Features
- Implemented in Verilog HDL
- Supports R-type, I-type, Load/Store, Branch
- ALU, Register File, Control Unit
- Simulation verified using testbench

## Tools Used
- Icarus Verilog
- GTKWave
- VSCODE
